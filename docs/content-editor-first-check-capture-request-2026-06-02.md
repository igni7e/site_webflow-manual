# Content Editor初回確認キャプチャー撮影指示書

## 撮影目的

Webflowを開いた直後に、読者が「正しいサイトを開いている」「最新版Content editor roleで開けている」「どこからCMSやAssetsを確認できる」を理解できる画像を撮影します。

この画像は、マニュアルの `02-editor/02-open-content-editor.md` に差し込みます。

## 保存ファイル名

`src/assets/captures/manual/b-02-content-editor-first-check.png`

## 撮影する画面

最新版のContent editor roleで、対象サイトを開いた直後のWebflow canvas画面を撮影します。

旧Legacy Editorの下部バーが出ている画面ではなく、新しいWebflow UIで撮影してください。

## 撮影前の準備

1. Webflow Dashboardで対象サイトを確認します。
2. `Open in Webflow` からサイトを開きます。
3. 画面が完全に読み込まれるまで3〜5秒待ちます。
4. `Loading...`、スピナー、画像未読込、空白カードが残っていないことを確認します。
5. 編集可能なテキストまたは画像にカーソルを合わせ、青いアウトラインや編集アイコンが出る状態にします。
6. 左側のCMSまたはAssets入口が見える状態にします。

## 必ず写すもの

- 対象サイト名または対象サイトだと分かる見出し
- ページ上の編集可能なテキスト、画像、またはリンク
- 編集可能状態を示す青いアウトライン、編集アイコン、または選択状態
- 左側メニューのCMSまたはAssets入口
- 上部バーの画面文脈

## 写さないもの

- 個人名、メールアドレス、通知内容
- 未公開ページ名、未公開記事タイトル、下書き本文
- 問い合わせ内容、フォーム送信履歴
- 請求情報、カード情報、プランの料金明細
- APIキー、カスタムコード、計測タグ
- 他社サイト名や他社Workspace名

## 推奨構図

横長の画面全体を撮影します。ボタンだけを拡大せず、左メニュー、上部バー、canvas上の編集可能要素が同時に分かる画角にしてください。

対象要素を画面中央付近に置き、青いアウトラインまたは編集アイコンが読み取れる状態にします。必要であれば、個人情報や未公開情報は撮影前に別ページへ移動するか、撮影後にマスクしてください。

## NG例

- Legacy Editorの画面が写っている。
- Designerの右パネルやStyle設定が主役になっている。
- CMSやAssetsの入口が見えない。
- 編集可能な要素がどれか分からない。
- ロード中、スピナー、画像未読込が残っている。
- 個人情報や未公開記事名が写っている。

## 撮影後チェック

- ファイル名が `b-02-content-editor-first-check.png` になっている。
- 保存先が `src/assets/captures/manual/` になっている。
- 最新版Content editor roleの画面だと分かる。
- 左側のCMSまたはAssets入口が見える。
- 編集可能な要素の青いアウトラインまたは編集アイコンが見える。
- 個人情報、未公開情報、請求情報が写っていない。
