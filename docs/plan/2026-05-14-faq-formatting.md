# 2026-05-14 FAQ表示改善計画

- [x] FAQ/Q&Aのあるページを洗い出す
- [x] QとAが詰まっている箇所を、見出し・段落・details形式で読みやすく整える
- [x] Markdown崩れと太字記法の残りを確認する

## 方針

- FAQの本文内容は大きく変えず、表示の読みやすさを優先する。
- 質問は見出しまたはdetailsのsummaryにして、回答は別段落に分ける。
- 絵文字は使わない。
- 既存URLや章構成は変更しない。
