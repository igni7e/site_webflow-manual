# 2026-05-14 AI向けキャプチャー指示追加計画

- [x] 既存の画像撮影指示書をAI実行向けに拡張する
- [x] 現在閲覧中のCMSファイル添付ページへ、具体的なキャプチャー指示を追加する
- [x] CMS・Designer・Settingsの主要ページに、撮るべき画面が分かる指示ブロックを追加する
- [x] Markdown崩れ、太字記法、ビルドを確認する

## 方針

- AIがそのまま作業できるよう、「撮影画面」「事前状態」「強調箇所」「隠す情報」「保存名」「差し込み位置」まで書く。
- 公開マニュアル本文では、読者の邪魔にならないよう、撮影指示は折りたたみ式の `<details>` にする。
- 実キャプチャー未取得の段階では、画像リンクを無理に増やさず、まず撮影指示を増やす。
- 絵文字は使わない。
