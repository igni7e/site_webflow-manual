# 2026-05-14 絵文字削除とMarkdown強調表現への統一計画

- [x] 絵文字・装飾記号が残っているMarkdownを洗い出す
- [x] 注意・ヒント・不可などの表現をblockquoteまたは通常テキストへ置き換える
- [x] 表や本文で使っている記号アイコンを文字表現へ置き換える
- [x] ビルドと差分チェックで検証する

## 方針

- 絵文字は使わない。
- 注意や補足は `> **注意**:`、`> **ヒント**:`、`> **重要**:` のようなMarkdown blockquoteで表現する。
- 可否表現は `可`、`不可`、`対象外` などのテキストにする。
- Webflowやコード識別子はそのまま残す。
