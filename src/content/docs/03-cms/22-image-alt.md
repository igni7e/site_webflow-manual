> 新規追加（標準スコープ補完）

ブログ記事や本文に画像を挿入する際、必ず入れてほしいのが <strong>alt 属性（代替テキスト）</strong> です。これは画像を「文字で説明する」ための情報で、SEO とアクセシビリティの両面で重要です。
*実画面例: 画像altを考える時は、ページ上でその画像が何を伝えているかを確認します。*

---

## 1. alt 属性とは？

`alt` は "alternative text（代替テキスト）" の略で、<strong>画像が表示できない時に代わりに表示される文字</strong> のことです。次のような場面で使われます：

- <strong>検索エンジン（Google など）</strong> が画像の内容を理解する際の手がかり
- <strong>音声読み上げソフト</strong>（視覚障がい者向け）が画像を音声で説明する際
- <strong>通信状況が悪く画像が表示されない時</strong> のテキスト表示
- <strong>画像検索結果</strong> にヒットする可能性が上がる

## 2. なぜ重要なのか？

- <strong>SEO</strong>: Google は alt テキストで画像の内容を理解します。記事のテーマに合った alt は <strong>記事全体の SEO 評価</strong> にもプラスです
- <strong>アクセシビリティ</strong>: 視覚障がいのある方も含め、全ユーザーが情報にアクセスできるようになります（WCAG 準拠）
- <strong>法的要件</strong>: 一部の業種・公共機関ではアクセシビリティ対応が義務化されています

## 3. CMS で alt を入力する方法

### ブログ記事の本文に挿入する画像の場合

1. 本文エディタで画像をクリック
2. 表示される設定パネルの <strong>「Alt text」</strong> または <strong>「代替テキスト」</strong> 欄に説明を入力
3. Save をクリック

### アイキャッチ画像（サムネイル）の場合

1. CMS のアイテム編集画面で、アイキャッチ画像をクリック
2. <strong>「Alt text」</strong> 欄に説明を入力
3. 記事を保存（Save Draft または Publish）

## 4. 良い alt の書き方

- <strong>画像の内容を簡潔に説明する</strong>（10〜80文字程度）
- <strong>記事のキーワードを自然に含める</strong>（無理にキーワード詰め込みはNG）
- <strong>「画像」「写真」という言葉は不要</strong>（「〜の写真」のように書かない）
- <strong>装飾目的だけの画像は空欄でもOK</strong>（読み上げ時にスキップさせる）

### 例

| 画像 | NG な alt | OK な alt |
|---|---|---|
| 大阪城の写真 | 画像 | 大阪城の天守閣を桜と共に撮影した写真 |
| 製品のロゴ | logo.png | IGNITE 株式会社のロゴ |
| 装飾の波線 | 波 | （空欄でOK） |

## 5. よくある質問 (Q&A)

#### Q. alt を入れ忘れるとどうなりますか？

サイトは正常に動きますが、検索エンジン評価とアクセシビリティが下がります。<strong>全画像に入れる習慣</strong> をつけましょう。


#### Q. 同じ記事に複数の画像がある場合、それぞれに違う alt を入れるべきですか？

はい。<strong>各画像の内容に応じて個別に</strong> 入力してください。同じ alt を使い回すのは避けましょう。
