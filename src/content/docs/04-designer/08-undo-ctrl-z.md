> 旧マニュアル番号: [No.45](/04-designer/08-undo-ctrl-z/)

<strong>【注意】この操作は「デザイナーモード」で行います。[No.38](/04-designer/01-designer-warning/)の注意点を必ず読んでから、自己責任の上で実行してください。</strong>

デザイナーモードでの作業は、常に危険と隣り合わせです。「間違って要素を消してしまった！」「数値を変更したらレイアウトが崩れた！」そんな青ざめるような事態は、誰にでも起こり得ます。しかし、慌てる必要はありません。ほとんどのPCアプリケーションと同じように、Webflowにも強力な「元に戻す」機能が備わっています。

---

## 1. 「元に戻す」ショートカットキー

デザイナーモードで直前の操作を取り消したい時、以下のキーボードショートカットを使います。これは絶対に覚えておいてください。

-   <strong>Windowsの場合:</strong> `Ctrl` + `Z`
-   <strong>Macの場合:</strong> `Command (⌘)` + `Z`

このキーを押すたびに、操作が一段階ずつ過去に遡っていきます。2回押せば2つ前の操作に、3回押せば3つ前の操作に戻ります。

## 2. 「やり直す」ショートカットキー

「元に戻す」操作を取り消して、未来の操作に一段階進めたい（元に戻しすぎた場合など）は、以下のショートカットキーを使います。

-   <strong>Windowsの場合:</strong> `Ctrl` + `Shift` + `Z`
-   <strong>Macの場合:</strong> `Command (⌘)` + `Shift` + `Z`

## 3. この機能が役立つ場面

-   <strong>要素を誤って削除・移動してしまった時:</strong>
    すぐに `Ctrl+Z` を押せば、削除した要素が元通りに現れます。

-   <strong>スタイルパネルの数値を変更してデザインが崩れた時:</strong>
    焦らず `Ctrl+Z` を数回押して、元の状態に戻るまで操作を遡ります。

-   <strong>何かよくわからないけど、表示がおかしくなった時:</strong>
    とにかく `Ctrl+Z` を押してみるのが有効です。直前の何気ない操作が原因だった、ということがよくあります。

## 4. パネルからも操作可能

ショートカットキーを忘れてしまった場合でも、デザイナーモードの左上にあるパネルから操作できます。

-   <strong>元に戻す:</strong> 左向きの矢印アイコン
-   <strong>やり直す:</strong> 右向きの矢印アイコン

## 5. 【重要】「元に戻す」の限界

この「元に戻す」機能は、デザイナーモードを<strong>開いている間</strong>の操作履歴を記憶しているものです。一度デザイナーモードを閉じてしまったり、ブラウザを更新してしまったりすると、<strong>操作履歴はリセットされます。</strong>

また、<strong>「Publish（公開）」してしまった変更を、この機能で元に戻すことはできません。</strong> Publishする前には、必ずプレビューで表示がおかしくないかを確認する癖をつけましょう。
