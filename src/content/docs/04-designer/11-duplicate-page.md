> 新規追加（標準スコープ補完）

「キャンペーンページの第2弾を作りたい」「サービスページに似た新しいページが欲しい」といった時、既存ページを **複製** することで、デザインを一から作らなくて済みます。

---

## 1. ページ複製のメリット

- **デザインの統一感** が保てる
- **作業時間の大幅短縮**（一からの設計が不要）
- **既存ページのレイアウトをベース** にできる

## 2. ページ複製の手順（Designer モード）

1. Designer モードで対象サイトを開く
2. 左サイドバーの **「Pages」** アイコン（紙のマーク）をクリック
3. 複製したいページを **右クリック**（または「・・・」メニューを開く）
4. **「Duplicate（複製）」** を選択
5. 新しいページが「ページ名 (1)」のような名前で作成される
6. 新ページを選択 → **Settings**（歯車アイコン）でページ名・URLスラッグを変更
7. 必要箇所をテキスト・画像差し替えで編集
8. **Publish** で公開

## 3. 複製後にやるべきこと

複製ページは **元ページの設定を引き継ぐ** ため、以下を必ず確認・修正してください：

| 項目 | チェック内容 |
|---|---|
| **ページタイトル（SEO Title）** | 元のままだと検索結果で重複扱い。必ず変更 |
| **メタディスクリプション** | 元のままだと SEO 上不利。新しいページ内容に合わせて書く |
| **OGP画像** | SNS シェア時の画像。新ページに合った画像に差し替え |
| **URLスラッグ** | 元と同じだと作成エラー。固有のスラッグに変更 |
| **本文** | 各セクションのテキスト・画像を新内容に差し替え |
| **CTA リンク** | フォームや問い合わせのリンク先が正しいか確認 |
| **アンカーリンク** | 内部の `#section` リンクが正しく動作するか確認 |

## 4. 注意事項

- **CMS テンプレートページ（記事ページなど）は複製できません**。CMS テンプレートは Designer の特殊な仕組みで動作するため、新規追加するには **CMS Collection の構造を Designer 側で設計** する必要があります（制作担当者にご相談ください）
- **複製後は必ず Publish が必要** です。複製しただけでは公開サイトには反映されません

## 5. よくある質問 (Q&A)

Q. 複製したページが Designer 上では見えるのに、公開サイトに表示されません。
A. 複製ページが **Draft（下書き）** 状態の可能性があります。Page Settings で「Draft」のチェックを外し、Publish を実行してください。

Q. 複製したページの URL を変えるにはどうすればいいですか？
A. Page Settings の **「Slug」** 欄を編集します。例: 元 `/campaign-spring` → 新 `/campaign-summer`

Q. 元ページに加えた変更を、複製ページにも反映させたいです。
A. 残念ながら **複製後は別ページとして独立** するため、自動同期はされません。両方を手動で更新するか、共通部分を **Components（コンポーネント）** として制作担当者に設計してもらう方法があります。
