# WORK-4. SEO設定を変えたい

## こんなときに使います

Google検索結果に表示されるページタイトルや説明文、SNSシェア時の画像を確認・変更したい時に使います。

SEO設定は公開後の見え方に影響します。文言変更だけでなく、検索結果として自然に読めるかも確認しましょう。

## 必要な準備

- 対象ページのURL
- 変更後のSEO title
- 変更後のmeta description
- OGP画像を変える場合は画像ファイル
- 参考ページ: [F-1. フォーム回答・CSV・プラン変更の確認ガイド](/05-settings/00-site-settings-complete-guide/)

## 手順

1. Site settingsまたはPage settingsを開きます。
2. SEO settingsを探します。
3. Title tagを確認します。
4. Meta descriptionを確認します。

:::note[キャプチャー指示]
撮影する画面: SEO titleとmeta descriptionの入力欄が見えている設定画面。
保存ファイル名: `work-04-edit-seo-settings.png`
撮影直前の状態: 対象ページのSEO設定欄が表示されている状態。
必ず写すもの: Title tag、Meta description、対象ページ名。
写さないもの: 非公開ページ名、個人情報、APIキー、請求情報。
:::

5. 必要な箇所だけ変更します。
6. 文字数が長すぎないか確認します。
7. OGP画像を変える場合は画像の見え方を確認します。
8. Publish後、公開ページと検索表示の反映タイミングを確認します。

:::caution[検索結果の反映]
PublishしてもGoogle検索結果はすぐに変わらない場合があります。緊急の変更では、Search Consoleの対応が必要になることがあります。
:::
