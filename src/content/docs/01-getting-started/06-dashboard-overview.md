> 旧マニュアル番号: No.6

Webflowにログインすると、最初に表示されるのが「ダッシュボード」です。ここからサイトの編集や設定など、様々な操作を開始します。このマニュアルでは、ダッシュボードの基本的な画面構成と各部の役割について解説します。

---

## 1. ダッシュボードの全体像

Webflowのダッシュボードは、あなたがアクセス権を持つサイトの一覧が表示される場所です。複数のサイトに関わっている場合は、ここに複数のサイトが並びます。

通常、クライアントとして招待された場合は、編集対象のサイトが1つだけ表示されているはずです。

**ダッシュボードの主な構成要素:**

- **サイト一覧:** 中央に、あなたが編集できるサイトのサムネイル画像が表示されます。
- **サイト名:** 各サイトのサムネイルの下に、サイト名が表示されます。
- **（右上の）アカウント設定:** 画面右上のアイコンから、ご自身のアカウント情報（名前やパスワードの変更など）を編集できます。
- **（左上の）Webflowロゴ:** Webflowのホーム画面に戻るためのロゴです。

## 2. サイトを選択して編集を開始する

サイトの更新作業を始めるには、このダッシュボードから目的のサイトを選択する必要があります。

1.  **サイトを探す:**
    ダッシュボードに表示されているサイトの中から、編集したいサイトを見つけます。

2.  **サイトにカーソルを合わせる:**
    サイトのサムネイル画像の上にマウスカーソルを合わせます。

3.  **「Editor」ボタンをクリック:**
    カーソルを合わせると、いくつかのボタンが表示されます。この中から、鉛筆のアイコンが付いた**「Editor」**というボタンをクリックしてください。

    ![ダッシュボードからEditorを開く](https://uploads-ssl.webflow.com/xxxxxxxx/xxxxxxxx_EditorButton.png)  
    *※画像はイメージです。実際のボタン配置は若干異なる場合があります。*

## 3. 「Editor」と「Designer」

サイトにカーソルを合わせた際、「Editor」の他に「Designer」というボタンも表示されます。この2つの違いは非常に重要です。

- **Editor（エディター）:**
  -   **普段の更新作業で使うモードです。**
  -   文字の修正、画像の差し替え、お知らせやブログの投稿など、日常的な更新はすべてこのモードで行います。
  -   操作がシンプルで、誤ってサイトのデザインを壊してしまう心配がありません。

- **Designer（デザイナー）:**
  -   サイトの構造やデザインそのものを編集する、より専門的なモードです。
  -   Webサイト制作会社がサイトを構築する際に使用します。
  -   **基本的に、クライアント様がこのモードを操作する必要はありません。** 誤って操作すると、サイトのレイアウトが崩れるなどのトラブルの原因となります。

## 4. まとめ

- **ダッシュボードは、サイト編集の入り口。**
- **サイトを更新する時は、必ず「Editor」ボタンから始める。**
- **「Designer」は専門家用なので、触らないようにする。**
