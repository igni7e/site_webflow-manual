> 旧マニュアル番号: [No.12](/02-editor/04-add-link/)

サイト内の別ページに訪問者を誘導したり、関連する外部サイトを紹介したりするために、文章に「リンク」を設定する機能は不可欠です。エディターを使えば、特定のキーワードや文章をクリックすると指定したページに移動させることができます。

---

## 1. リンク設定の基本ステップ

1.  <strong>リンクを設定したい文字を選択する</strong>
2.  <strong>表示されるメニューから「Link」アイコンをクリックする</strong>
3.  <strong>リンク先のURLを入力する</strong>
4.  <strong>設定を確定し、変更を保存する</strong>

## 2. 操作手順の詳細

1.  <strong>リンクを設定したい文字を選択:</strong>
    「[No.11](/02-editor/03-bold-text/)」と同様に、リンクを設定したいテキストをマウスでドラッグして選択します。

2.  <strong>フローティングメニューを表示:</strong>
    文字を選択すると表示されるフローティングメニューから、鎖の形をした「<strong>Link</strong>」(Link) アイコンをクリックします。

3.  <strong>リンク先URLの入力欄を表示:</strong>
    クリックすると、URLを入力するためのボックスが表示されます。

    :::note[キャプチャー差し込み位置]
    ここには「リンク設定画面」が分かる実画面キャプチャーを入れてください。ページ上部のキャプチャー指示にある保存ファイル名へ差し替えます。
    :::

4.  <strong>URLを入力または貼り付け:</strong>
    入力欄に、移動させたいページのURLを正確に入力します。URLをコピーしてある場合は、ここに貼り付けると間違いがありません。

    -   <strong>外部サイトへのリンクの場合:</strong> `https://` から始まる完全なURL（例: `https://www.google.com`）を入力します。
    -   <strong>サイト内の別ページへのリンクの場合:</strong>
        -   `/` から始まる相対パス（例: `/service` や `/contact`）を入力するのが簡単です。
        -   または、そのページの完全なURL（例: `https://あなたのサイト名/service`）を入力しても構いません。

5.  <strong>【重要】外部リンクの場合は「別タブで開く」を設定</strong>
    自分のサイトとは別の外部サイトにリンクを設定する場合、訪問者が元のサイトに戻りやすいように、リンク先を新しいブラウザタブで開く設定が推奨されます。
    URL入力欄の右側にある、<strong>四角から矢印が飛び出しているアイコン（Open in new tab）</strong>をクリックしてオンにしてください。アイコンが青色になれば設定完了です。

6.  <strong>設定を確定:</strong>
    URLの入力と設定が終わったら、入力欄の外側をクリックするか、キーボードのEnterキーを押すと設定が確定されます。リンクが設定された文字は、通常、色が変わったり下線が付いたりします。

## 3. リンクを解除・編集する方法

- <strong>リンクの解除:</strong> リンクが設定されている文字を再度クリックし、表示されるURLの隣にある「<strong>Link</strong>に斜線が入ったアイコン（Unlink）」をクリックすると、リンクだけを解除できます。
- <strong>リンクの編集:</strong> リンクが設定されている文字をクリックし、表示されるURLをクリックすると、再度URLを編集できます。

## 4. 【重要】変更の公開

作業後は、必ず「[No.15](/02-editor/07-save-and-publish/)」の手順に従って、変更を<strong>公開（Publish）</strong>してください。
