:::tip[編集の基本]
コンテンツエディターでは、文章、画像、リンクなどの内容を安全に更新できます。レイアウトやデザインを変えたい時は、Designer操作が必要か確認してください。
:::
<!-- body-callout:end -->


文章の中で特に強調したいキーワードや文言がある場合、「太字」機能を使うと効果的です。Content editor roleでは、Wordなどの文書作成ソフトと同じような感覚で、文字を太字に装飾できます。

---

## 1. 太字にするための基本ステップ

1.  太字にしたい文字を選択する
2.  表示されるメニューから「B」アイコンをクリックする
3.  変更を保存する

## 2. 操作手順の詳細

1.  Content editor roleで編集状態にする:
    [エディターでサイトの文字を書き換える方法](/02-editor/03-edit-text/)の手順で、まずは太字にしたい文字が含まれるテキストブロックをクリックし、編集できる状態にします。

2.  太字にしたい文字をドラッグして選択:
    マウスを使って、太字にしたい部分のテキストをドラッグ（マウスの左ボタンを押したままなぞる）して、反転表示させます。

3.  フローティングメニューを表示させる:
    文字を選択すると、そのすぐ上に小さな黒いメニュー（フローティングメニュー）が自動的に表示されます。

    ![テキスト編集状態](../../../assets/captures/manual/b-03-editable-text-active.png)

4.  「B」アイコンをクリック:
    メニューの中にある「B」（Boldの頭文字）のアイコンをクリックします。

5.  太字になったことを確認:
    クリックすると、選択していた文字が即座に太字になります。意図した通りに太字になったかを確認してください。

6.  太字を解除する場合:
    間違えて太字にしてしまった場合や、元に戻したい場合は、もう一度同じ箇所を選択して、再度「B」アイコンをクリックすると太字が解除されます。

## 3. その他の文字装飾

このフローティングメニューには、太字以外にもいくつかの装飾機能があります。

- _I_ (Italic): 文字を *斜体* にします。デザインにもよりますが、引用や少しニュアンスを変えたい時に使います。
- Link (Link): 選択した文字にリンクを設定します。詳しくは[エディターで文章にリンクを設定する方法](/02-editor/05-add-link/)で解説します。

## 4. 【重要】変更の公開

この作業が終わった後も、変更を実際のサイトに反映させるためには「公開（Publish）」作業が必要です。
忘れずに「[変更を保存してサイトに反映させる方法](/02-editor/08-save-and-publish/)」を実行してください。
