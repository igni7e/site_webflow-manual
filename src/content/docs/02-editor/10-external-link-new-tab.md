:::tip[編集の基本]
コンテンツエディターでは、文章、画像、リンクなどの内容を安全に更新できます。レイアウトやデザインを変えたい時は、Designer操作が必要か確認してください。
:::
<!-- body-callout:end -->

自社サイト外のページ（パートナー企業、SNS、外部記事など）にリンクを貼る際は、<strong>新しいタブで開く設定</strong> にしておくのがおすすめです。これにより、訪問者が自社サイトから離脱せずに済みます。

---

## 1. なぜ「新しいタブで開く」が良いのか？

- <strong>離脱防止</strong>: 訪問者が外部リンクを踏んでも、元のページが残っているのですぐに戻ってこれます
- <strong>SEO 観点</strong>: 「滞在時間」が伸びやすく、ユーザビリティが向上します
- <strong>スマホで特に有効</strong>: スマホは「戻る」操作がやや煩雑なので、新しいタブの方が快適です

逆に、<strong>自社サイト内のリンクは同じタブで開く</strong> のが標準です（戻りやすい/履歴が綺麗）。

## 2. エディターでの設定手順

1. リンクを貼りたいテキストを選択します
2. 表示されたツールバーの <strong>リンク（鎖アイコン）</strong> をクリックします
3. URL を入力するパネルが開きます
4. URL を入力（例: `https://example.com`）
5. <strong>「Open in new tab（新しいタブで開く）」のチェックボックスをONにします</strong>
6. <strong>Save</strong> ボタンをクリックして保存

:::note[キャプチャー差し込み位置]
リンク設定パネルで `Open in new tab` のチェックボックスが見える画面をここに追加します。保存ファイル名は `src/assets/captures/manual/b-10-open-in-new-tab-setting.png`。対象テキストを選択し、URL入力欄とチェックボックスが表示されている状態で撮影してください。
:::

## 3. 既存のリンクを「新しいタブで開く」に変更する

1. リンクが貼られているテキストをクリック
2. ツールバーの <strong>編集（鉛筆アイコン）</strong> をクリック
3. URL 編集パネルで <strong>「Open in new tab」をON</strong>
4. Save をクリック

:::tip[確認する場所]
外部サイト、PDF、SNSへのリンクは新しいタブで開く設定にします。自社サイト内の別ページへ移動する通常リンクは、基本的に同じタブのままで問題ありません。
:::

## 4. よくある質問 (Q&A)

#### Q. 自社サイト内のリンクも新しいタブで開くべきですか？

いいえ、基本的には <strong>同じタブ</strong> で開いてください。サイト内回遊では「戻るボタン」が使えた方がユーザーは安心です。


#### Q. PDF へのリンクはどうすべきですか？

<strong>新しいタブで開く</strong> をおすすめします。PDF はブラウザによっては表示に時間がかかったりダウンロードされたりするため、元のページが残っていると安心です。
